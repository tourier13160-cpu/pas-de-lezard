4. Statistiques d'une vague

Le tableau à montrer à un partenaire : inscrits, qualifiés, chrono moyen, rejets.

Que font ces boutons, exactement ?
Créer la vague : Programme une session avec les réglages choisis. Les inscriptions s'ouvrent selon le délai indiqué, et se ferment 1 minute avant le départ. Tester tout de suite : Programme une vague qui démarre dans 2 minutes, inscriptions déjà ouvertes. Pratique pour vérifier que tout fonctionne. État des vagues : Liste tes vagues avec leur phase : upcoming = pas encore ouverte aux inscriptions registration = inscriptions OUVERTES (c'est ce que tu veux voir) locked = inscriptions fermées, départ imminent running = la partie est en cours finished = la fenêtre de réponse est close drawn = les lots ont été attribués Statistiques : Inscrits, qualifiés, chrono moyen, nombre de réponses trop rapides (bots), réclamations de lots.
